# 文章ルール

- 各H2の直下は、まずそのH2の結論を1〜2文で書く。H2の直後にいきなりH3を置かない。
- 「結論 → 理由 → 具体例 → 注意点」の順で書く。
- 1文は40〜70文字が目安。1つの `<p>` には1〜2文まで。
- テーマに関係する検索意図（時期・料金・所要時間・服装・持ち物・アクセス・子連れ・初心者・雨天時・予約タイミングなど）を本文で自然に回収する。
- 同じ内容の言い換えや、文字数を増やすだけの文章は書かない。
- 文字数は3,000〜5,000字が目安。テーマと上位記事の情報量に合わせて調整する。
- 強調（`<strong>`、色付き `<span>`）は、読者が判断に迷う箇所だけに使う。
- 一次情報（天候・海況・潮位・風向きによる開催判断、集合場所、所要時間の実態、子連れ・初心者の判断基準など）は、島jsonの `facts` や確認できた公式情報の範囲で書く。根拠のない実績・受賞・人数・「絶対安全」などは書かない。
- 最後は必ず `<h2>さいごに</h2>` で締め、島jsonの `cta_activity` を置く。
